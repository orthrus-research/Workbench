# Workbench modules

Modules contain product-generic behavior and contracts:

- [Workbench Shell](workbench-shell/README.md): surface-neutral orchestration,
  component/session/consent boundaries, terminal menus, exact-option wizards,
  lossless live timelines, private sessions, and retained replay;
- [Exact Runtime Explorer](runtime-explorer/README.md): authority-preserving
  identity search across static project/artifact structure, observed runtime
  evidence, retained output, and Manuals;
- [Pack Program Studio](pack-program-studio/README.md): exact GroovyScript
  lifecycle and dependency inventory, profile-classified static effects,
  semantic comparison, runtime-log correlation, exact upstream
  canonicalization diagnostics, and reload/save guidance;
- [GTCEu Subsurface Studio](subsurface-studio/README.md): bounded ore,
  lithology, final cave-space, virtual-fluid, coordinate, section, and aligned
  comparison views over exact profile-owned inputs;
- [Worldgen Cockpit](worldgen-cockpit/README.md): paired fresh-world
  orchestration and aligned semantic, exact-state, statistical, causal, and
  performance comparison with an explicit A/A reproducibility gate;
- [Worldgen Qualifier](worldgen-qualifier/README.md): pack-owned perturbation
  matrices, fail-closed domain/evidence acceptance, and generic exact-JAR
  nondeterminism risk screening over repeated Cockpit controls;
- [Project Intelligence](project-intelligence/README.md): independently
  runnable native-project recognition and exact workspace, platform, pack,
  revision, artifact, and static Mixin topology context;
- [Atlas](atlas/README.md): game knowledge and relationship queries;
- [Blueprints](blueprints/README.md): feature planning, generation, testing,
  application, and debugging;
- [Crucible](crucible/README.md): controlled runtime experiments, disposable
  runtime/world custody, and exact local operation receipts;
- [Sentinel](sentinel/README.md): plain-English presentation of findings that
  remain authorized by exact profile policies, standards, invariants, and
  owner evidence;
- [Relay](relay/README.md): exact, read-only identity handoff from retained
  Atlas or Crucible evidence to owner-backed source and evidence locations;
- [Manuals](manuals/README.md): developer-facing implementation guidance.

Exact Cleanroom and pack behavior belongs in `profiles/`, even when a module
provides the engine that consumes it.
