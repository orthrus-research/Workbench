# Atlas material source/runtime comparison V2

Status: experimental material-first authority

This lens compares Pack Program Studio material declarations with one admitted
Atlas categorical graph set. Frozen runtime state remains the observation;
source intent never overwrites it.

Registration facets compare numeric identity, properties, explicit flags, and
composition. A declaration is an exact-set claim only when both its verified
closure and overall normalization are exact. Metaprogrammed or unresolved
composition makes properties and flags lower bounds, so additional runtime
facts remain a frontier rather than a contradiction.

Mutation constraints are evaluated independently. Required properties and
flags use inclusion semantics. Formula comparison recognizes GTCEu's Unicode
subscript rendering while retaining both original values. Requested fluid
storage keys are checked only against the separate material/fluid partition.

Aggregate states are `parity`, `frontier`, `difference`, `runtime-only`,
`source-only`, `ambiguous-source-registration`, and retained subordinate
missing states. A difference is an investigation candidate; without a
capture-bound operation ledger it does not prove which Groovy operation
executed or caused the frozen value.
