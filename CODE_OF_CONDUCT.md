# Workbench code of conduct

Workbench welcomes constructive participation in its issues, pull requests,
and other project spaces. Be respectful, discuss the work rather than attacking
people, and respect others' time and privacy.

Harassment, threats, discriminatory abuse, personal attacks, spam, and sharing
someone else's private information without permission are not acceptable.

To report a conduct concern privately, email [zestehl@pm.me](mailto:zestehl@pm.me)
with "Workbench conduct report" in the subject. Include links or context that
will help review the concern. Do not post the report in a public issue. Security
vulnerabilities use the separate route in [SECURITY.md](SECURITY.md).

`zestehl` is the responsible maintainer. The maintainer will review reports as
privately as practical and may remove content, lock a conversation, or restrict
participation. Workbench currently has one maintainer, so independent review
is not yet available.
