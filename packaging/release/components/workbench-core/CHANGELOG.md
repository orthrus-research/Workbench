# Workbench Core changelog

## 0.1.6

- Show installed Java versions and exact profile compatibility before selection.
- Refuse a different JVM build whose version merely shares the required prefix.

## 0.1.3

- Establish the `public-v1` Workbench Core package route.
- Publish one explicit runtime/resource allowlist with V5 portable, wheelhouse,
  and native manifests.
- Declare independent `workbench-core/v0.1.3` tags and namespaced artifacts.
- Use the Host Adapter V3 identity and descriptor binding for host integration.
